# 推し先祖宣言

## 先祖との関係を、現代に再設計する

「推し先祖」は、先祖を単に調査する対象としてではなく、  
知り、思い、楽しくつながり、関係を育てる存在として捉え直すプロジェクトです。

> 先祖を「調べる対象」から、  
> 楽しくつながり、関係を育てる存在へ。

戸籍、家系図、写真、土地、墓参り、家族の記憶。  
それらを、カード、地図、音、物語、星空などの表現へ変えながら、  
現代の暮らしに合った先祖とのつながり方をつくっています。

---

## 思い出すことが、敬いになる

人は、忘れられてはじめて死を迎える。  
推し先祖は、思い出すことそのものを、新しい敬いの形と考えます。

名前と線で「つながり」を残す家系図の、もうひとつの形として。  
好きだったもの、声、ゆかりの場所。その人の「存在の手触り」を、一人ずつ残していく。

そして、先祖を思い出すことが、  
「わたし」を知ることにつながっていく。

## 大戸籍時代

推し先祖は、戸籍情報のデジタル化や利用環境の変化によって、  
多くの人が自分や家族の記録に触れるようになるこれからの時代を、  
**「大戸籍時代」**と呼びます。

戸籍を取得して保管するだけでなく、  
そこに記された一人ひとりを人として思い出し、  
写真、土地、仕事、出来事、家族の記憶へつないでいく時代です。

## 主なプロジェクト

- 推し先祖クリップ
- 推し先祖プロフ帳
- 足あとタイムライン
- 戸籍とりよせ帖
- 巡礼
- 星空家系図
- おもかげ

星空家系図は、家族や先祖の関係を星と星座のように表現し、  
ASMR、環境音、音楽、語りなどの癒やしの要素を組み合わせる、  
新しい家系図体験を目指しています。

音声作品「或る駅」やポッドキャスト「眠れない夜の音」などで培った、  
音、物語、余白、記憶を重ねる制作スタイルを活用しています。
